# 审稿与验收

先在目标设备宽高渲染。把「自动通过」与「肉眼合格」分开写。

| 检查 | 通过标准 | 失败时 |
|---|---|---|
| 叙事 | 页序和原框架一致，封面能定题，最后落到明确动作 | 重新排页或删重复概念页 |
| 证据 | 指标有单位/期间，案例和引语有来源，示例有标注 | 隐去无来源信息，保留待补项 |
| 审美 | 缩略图一眼找到焦点，全尺寸能读字和图 | 先减字、裁图、拉开层级，再微调 |
| 画面 | 无溢出、遮挡、残行、拉伸、丢字体和缺资源 | 回到目标渲染逐页确认 |
| 编辑性 | 需要编辑的标题、数字、图表和结构仍为原生对象 | 检查文件内部对象或在目标应用试改 |
| 播放 | 下一页/上一页/深链、停止、媒体、离线、减少动态可用 | 现场无网测试，准备静态备份 |
| 分发 | 文档、原件、截图和链接只面向允许读者，外发口径核对 | 替换成样例或留在权限受控的资产库 |

用 0/1/2 打分：0 缺失，1 可修，2 可交付。证据、关键文本溢出、目标文件打不开、权限越界任一为 0，不能交付。动画没有实播就写「未实播」。
