# 一页一张决策卡

先做一张可审阅的页表，每行对应交付的一页。录入未知项，不能因为版式需要而补造证据。

| 字段 | 例子 |
|---|---|
| 页号 / 作用 | 04 / 让负责人选择先做哪个试点 |
| 主标题 | 先验证能当天交付的任务 |
| 台词 / 阅读场景 | 口播 20 秒；无口播也能理解重点 |
| 证据 | 实测记录第 2 节；未验证的响应时间不入稿 |
| 页面构成 | 左侧结论，右侧可编辑三行筛选矩阵 |
| 动效 | 逐步高亮证据列；PDF 显示完成状态 |
| 下一页关系 | 候选筛选 → 单一试点执行计划 |
| 待确认 | 试点责任人与输入样本；移入讲稿或回传清单 |

顺序建议：开场界定任务 → 展示核心做法或直接演示 → 证据 → 范围 / 取舍 → 下一步。参考框架指定顺序时，以原顺序为准。来源标识贴在证据附近或写进讲稿备注。
