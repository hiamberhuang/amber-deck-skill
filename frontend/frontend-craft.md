# 前端工艺总则（固定画布 HTML deck）

这套参考回答一个问题：拿到每页文案之后，怎样把一页 16:9 的 HTML 做到设计工作室的完成度。它只管前端工艺，不重复两处已有的内容：设计令牌和页面原型在 `../style/`，动效在 `../motion/`。

所有数值按 **1440×810 画布**给出，与 `../style/tokens.css` 一致。换到 1920×1080 时，尺寸类乘 1.333，比例类（行高、em 字距、对比度）不变。

每条规则都写成能检查的形式。能自动查的，`snippets/deck-lint.js` 里有对应规则名，写在方括号里。

## 0. 开工前先定五件事

写任何一页之前，先把下面五项写下来。写不出来说明这页还没想清楚。

1. **这页的主角是什么**：一个数、一张图、一句话、一个图解，只能选一个。其余元素都为它服务。
2. **读者三秒内要带走的一句话**：它就是标题。标题写结论（“华东区响应最快，转化也最高”），不写栏目名（“区域数据”）。
3. **用哪个原型**：从 `../style/` 的页面原型里选。相邻两页不用同一个原型，连续三页不能是同一种结构。
4. **强调色落在哪**：一页里强调色最多出现在三处，且指向同一件事（见 §3）。
5. **纵向预算**：把每块内容的高度加起来（字号 × 行高 × 行数 + 间距 + 上下边距），不超过 810。超了就拆页，不缩字。

## 1. 画布与缩放

**1.1 画布内只用 px。** 不用 vw、vh、rem、百分比字号。画布永远是 1440×810，整台等比缩放去适应窗口。这样任何屏幕上断行都一模一样，PDF 也一样。片段：`snippets/04-stage-scale.html`。

```css
#stage{position:absolute;left:0;top:0;width:1440px;height:810px;transform-origin:0 0}
```
```js
var s=Math.min(innerWidth/1440,innerHeight/810);
stage.style.transform='translate('+(innerWidth-1440*s)/2+'px,'+(innerHeight-810*s)/2+'px) scale('+s+')';
```

**1.2 用 `transform:scale`，不用 `zoom`。** `zoom` 会让文字按新尺寸重新排版，分数倍率下字宽取整不同，断行可能变。`transform` 只是把排好的画面放大缩小。

**1.3 翻页用 `visibility`，不用 `display:none`。** 隐藏页保留布局，字体和图片提前就位，截图和测量都稳定。翻页控件、页码、进度条放在 stage 外面，不跟着缩放。

**1.4 页码和页脚由外壳生成。** 不在每页里手写“3 / 12”。页眉页脚的左右边线必须和正文版心重合（都是 `--pad-x`）。

**1.5 测量坐标时注意缩放。** `getBoundingClientRect` 返回缩放后的值，`offsetLeft/offsetWidth` 返回未缩放的值。画连接线一律用 offset 系，或者把 rect 的差值除以缩放比。`snippets/13-flow.html` 用的是 offset 系。

## 2. 布局

**2.1 一条版心线。** 全 deck 左右边距统一为 `--pad-x`（68px）。标题、正文、图表、页脚的左边线是同一条线。检查方法：每页最左侧的可见内容，x 坐标只允许是 68 或有意出血的 0。

**2.2 间距取自一把尺。** 只用 4 的倍数，推荐序列 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96。出现 17、23、38 这种数说明是凑出来的。一页内的间距至少有“紧”和“松”两档：组内 8–16，组间 32–64。全页只有一种间距值是单调的标志。

**2.3 标题上方的空间大于下方。** 标题下到正文的间距，不超过标题上方间距的一半。标题属于它下面的内容。

**2.4 先用距离分组，再考虑容器。** 能靠留白和对齐说清楚关系的，不加边框、不加卡片。卡片只在两种情况下用：内容是一个可以独立拿走的对象（一个方案、一个案例、一张截图），或者需要把一块内容从背景里抬起来当主角。

**2.5 禁止卡片汤。** 三个以上同构、等大、同色的卡片并排，等于没有主次 `[card-soup]`。替换做法按内容性质选：

| 内容性质 | 换成 |
|---|---|
| 有先后 | 流程（`13-flow`）或时间线（`23-timeline`） |
| 有主次 | 一大带几小，大的占 55–62% 宽 |
| 可比较 | 表格（`17-table`）或同一把尺的条形（`14-before-after`） |
| 并列但其中一个是重点 | 其余合并成一个带分隔线的条带，重点单独成卡 |
| 两个维度 | 一个容器加十字线的矩阵（`25-matrix`），不是四张卡 |

**2.6 列数跟着条目数走。** 两条内容不排三列，五条内容不排成 3+2 留一个空位。四条可以 2×2，五条用 1 大 + 4 小或者改成列表。

**2.7 不嵌套超过两层。** 卡片里不再放带阴影的卡片 `[nested-shadow]`。卡内需要分区时用浅底色块或细分隔线（见 §4）。

**2.8 填满画布靠构图，不靠装饰。** 内容最低点以下的空白超过画布高度的 35% 要处理，超过 50% 是缺陷 `[empty-bottom]`。处理顺序：

1. 放大主角：字号、图、图解直接放大到撑满。
2. 改构图：左文右图的两栏垂直居中（`08`、`09`、`15`），或者标题在上、主角压在底部（`11-big-number`）。
3. 补证据：加一条来源、一组对照、一个参照物。
4. 和相邻页合并。

不允许的做法：加装饰图形、加无信息的图标、把字距行距拉大、加一句空话。

**2.9 修溢出不要过度删。** 内容溢出时按这个顺序处理：收紧间距一档、删修饰语、换原型、拆页。不缩小字号到下限以下，不把行高压到 1.4 以下，不裁掉边距。

**2.10 对齐默认靠左。** 正文、标题、图表标签都左对齐。居中只用于封面、章节页、引言页这类仪式性页面，且全页只有一个居中的块。数字列右对齐。

**2.11 光学对齐。** 几何对齐之后还要看三处：

- 行首的开引号、书名号向左悬挂半个字（`19-punctuation`）。
- 圆形、三角形图标要比方形图标略大（约 8–12%）才显得一样大；logo 墙按视觉面积归一（`07-logo-wall`）。
- 大字的字面左侧有内置空白，72px 以上的标题比正文向左多移 2–4px 才能看起来对齐。

**2.12 密度上限。** 一页一个核心信息，加三到四个支撑点。正文类页面汉字不超过 120 个（不含图表标签），要点每条一行、不超过五条。宣讲用的页面再减半。

## 3. 颜色

**3.1 一个强调色，四种用途。** 强调色只做这四件事：一个主块的底色、小标签、划重点、数据里要看的那一根。一页最多三处，面积合计不超过画布的 10%（主块页除外）。同一页上强调色必须指向同一件事，否则读者不知道看哪。

**3.2 色阶从强调色派生，往底色里混。** 不手调浅粉深红，用 `color-mix` 把强调色混进当前底色，这样暖白底和深底自动协调。片段：`26-tint-scale.html`。

```css
.slide{
  --a-08:color-mix(in oklch,var(--accent) 8%,var(--bg));   /* 标签底、重点行底 */
  --a-16:color-mix(in oklch,var(--accent) 16%,var(--bg));  /* 划重点 */
  --a-ink:color-mix(in oklch,var(--accent) 82%,var(--ink)); /* 小字用的加深强调色 */
}
```

**3.3 对比度下限（实测，不目测）。** 正文和 24px 以下的字 ≥ 4.5:1；24px 以上或 18.66px 以上且加粗 ≥ 3:1；图表里的线和形状 ≥ 3:1 `[low-contrast]`。

对 `tokens.css` 暖白底实测的结果，直接当规则用：

| 颜色 | 在 `--bg` 上 | 能做什么 |
|---|---|---|
| `--ink` #0E0F13 | 17.9:1 | 一切 |
| `--muted` #636874 | 5.2:1 | 可读小字的最浅颜色 |
| `--faint` #9AA0AB | 2.5:1 | **不能做文字**。只用于刻度线、禁用态、装饰大字 |
| `--accent` #E4003A | 4.50:1 | 正好卡线。24px 以上的字和图形放心用；小字改用 `--accent-deep` #C50033（5.7:1） |
| 白字压 `--accent` | 4.8:1 | 可以，但不能降透明度：`.86` 透明度只剩 3.8:1 |

**3.4 彩色底上的次要文字不用灰。** 强调色块上的小字用纯白，层级靠字号和字重拉开，不靠降透明度 `[low-contrast]`。

**3.5 中性色带一点底色的色相。** 分隔线、浅底、阴影都往底色的暖度偏，不用纯灰 `#ccc`、`#999`。阴影用 `rgba(20,18,22,…)` 这类带色相的黑。

**3.6 深色页单独配，不是反色。** 深底的层级靠表面亮度递增（底 → 卡片 → 浮层每级提亮几个百分点），不靠阴影。分隔线用 `rgba(255,255,255,.08–.12)`。强调色略降饱和。深底浅字看起来更粗，正文行高加 0.05–0.1，正文不用 600 以上的字重。

**3.7 一种颜色一个含义。** 数据色、状态色全 deck 含义固定。红色在这套令牌里是品牌强调色，因此“下降 / 负面”不用红，用文字和符号（−、↓）表达。

**3.8 背景色全 deck 只有一到两种。** 换背景色是有含义的事（章节切换、案例门面），不能为了“有变化”而换。

## 4. 深度

**4.1 全 deck 一套深度语言，只有三层。** 片段：`20-depth.html`。

| 层 | 做法 | 用在 |
|---|---|---|
| L0 画布 | `--bg` | 大部分内容直接放这层 |
| L1 白卡 | 白底 + 1px 发丝线 + 两段柔和阴影 | 被抬起来的主角、可独立拿走的对象 |
| L2 卡内分区 | 浅底 `--soft`，无阴影，无边框 | 卡片里的数据区、代码、引用 |

```css
/* L1：发丝线用 box-shadow 画，不占尺寸，也不会和阴影打架 */
.l1{background:var(--card);border-radius:var(--r-card);box-shadow:0 0 0 1px var(--line),var(--sh-1)}
.l2{background:var(--soft);border-radius:max(4px,calc(var(--r-card) - var(--pad) + 8px))}
```

**4.2 阴影的四条规矩。** 中性色；向下偏移；两段（贴地 1–2px 一段，环境 6–16px 一段）；透明度合计不超过 0.1。零偏移的彩色阴影是发光 `[glow]`，只允许出现在全页唯一的强调块下面，且必须向下偏移。

**4.3 圆角同心。** 内层圆角 = 外层圆角 − 内边距，最小 4px。父子同一个圆角值是错的。圆角全 deck 只有三档：卡片 `--r-card`，小标签 `--r-chip`，胶囊 999px。

**4.4 强弱对比同时拉开四样东西。** 要让一边压过另一边，底色、阴影、字重、字色四样一起变，只改一样看不出来。强的一侧可以比弱的一侧上下各高出 16–20px。片段：`10-comparison.html`。

**4.5 不用的手法。** 毛玻璃（`backdrop-filter` 在 PDF 里会丢）、渐变底卡片、左侧粗色条 `[side-stripe]`、粗边框加重阴影、内发光、噪点纹理。

## 5. 图片与素材

**5.1 图片永远不裸放。** 外面套一个容器，容器定比例和圆角，图片填满，焦点用变量指到主体上。片段：`21-img-frame.html`。

```css
.frame{position:relative;aspect-ratio:var(--ratio,16/10);border-radius:10px;overflow:hidden;background:var(--soft)}
.frame>img{position:absolute;inset:0;width:100%;height:100%;object-fit:cover;object-position:var(--pos,50% 50%)}
.frame::after{content:"";position:absolute;inset:0;border-radius:inherit;box-shadow:inset 0 0 0 1px rgba(0,0,0,.08)}
.frame.contain>img{object-fit:contain}
```

**5.2 裁切规则。**

- 照片用 `cover`，每张都要显式写 `--pos`，不写等于没看过这张图。
- 截图、图表、logo 用 `contain`，不裁。截图太长时只允许从底部裁，顶部对齐（`object-position:top`）。
- 比例只用 21:9、16:9、16:10、4:3、1:1、4:5。同一行的图片同一个高度。
- 人脸不贴边，眼睛在上三分之一；地平线不在正中。
- 不放大位图：显示宽度不超过原图像素宽度的一半（按 2 倍屏算）。

**5.3 截图要装框。** 产品截图直接贴在页面上会像贴了一张纸。网页截图装浏览器框（`05-browser-frame.html`），手机截图装机身（`06-phone-frame.html`）。框的做法：

- 浏览器框：圆角 12，顶栏 38px，三个 11px 的中性灰圆点（不用红黄绿），地址栏可选。
- 手机：机身圆角 = 屏幕圆角 + 边框厚度；只画机身和灵动岛，不画按键和反光。
- 阴影比普通卡片深一档（`0 24px 56px` 约 14% 透明度），因为它是页面主角。
- 截图内容必须真实可读，关键数字要和正文说的一致。

**5.4 图上压字用定向暗幕。** 暗幕只盖文字所在的角，以那个角为圆心向外渐隐，主体一侧保持原片亮度。文字正下方的暗幕不透明度 ≥ 0.66。文字和主体不能重叠，先用 `object-position` 把主体挪开。片段：`12-image-scrim.html`。自动检查无法判定图上文字的对比度，会报 `[text-on-image]` 提醒人工看。

**5.5 Logo。**

- 只用官方文件，不重画，不用文字假装 logo。拿不到就写公司名的纯文字，并在交付说明里列出缺失项。
- Logo 墙按视觉面积归一，不按统一高度：宽 = k × 比例^0.6，再夹住上下限。片段：`07-logo-wall.html`。
- 统一成单色（`currentColor`，或对位图用 `filter:grayscale(1)` 加 `opacity:.7`）。彩色 logo 墙会抢走全页的注意力。
- 每个 logo 四周留出自身高度一半的净空。

**5.6 图标。** 全 deck 一套图标库、一种线宽（1.5 或 1.8px）、一种尺寸档。图形在 24×24 的 viewBox 里几何居中。不用 emoji 当图标（无头 Chrome 里可能渲染成方框）。不给每个要点都配图标：图标只在它能替代文字或帮助扫读时才出现。

**5.7 不用代码画插画。** 不用 CSS 或 SVG 基本形状拼人物、产品、场景。SVG 只用来画几何关系：图解、图表、图标。需要画面感时用真实照片或截图；没有就留一个标注清楚的占位（写明需要什么图、什么比例），不要用渐变色块冒充。

## 6. 打印、PDF 与离线

**6.1 打印样式。** 片段 `04-stage-scale.html` 导出实测：两页，页面尺寸 1080×607.5pt（即 1440×810 CSS px）。

```css
@page{size:1440px 810px;margin:0}
@media print{
  html,body{height:auto;overflow:visible;background:none}
  #stage{position:static;transform:none!important;width:auto;height:auto}
  #stage .slide{position:relative;inset:auto;visibility:visible;break-after:page;break-inside:avoid}
  #stage .slide:last-child{break-after:auto}
  *{-webkit-print-color-adjust:exact;print-color-adjust:exact;animation:none!important;transition:none!important}
}
```

导出参数：`page.pdf({preferCSSPageSize:true, printBackground:true})`，先等 `document.fonts.ready`。

**6.2 PDF 里会出问题的东西。**

| 写法 | 在 PDF 里 | 改成 |
|---|---|---|
| 缩放用的 `transform:scale` 没撤 | 分页错乱或出空白页 | 打印样式里 `transform:none` |
| `position:fixed` | 每页重复出现 | 放到 stage 外并在打印时隐藏 |
| slide 的父级是 flex / grid | `break-after` 失效 | 打印时父级 `display:block` |
| `backdrop-filter` | 直接丢失 | 不用；或给不透明的兜底底色 |
| `filter:blur`、`mix-blend-mode` | 被栅格化，文件变大、放大发虚 | 不用 |
| 入场动画的初始态（透明、位移） | 被原样拍下来 | 打印时 `animation:none;opacity:1;transform:none` |
| 字体没加载完 | 静默回退，断行全变 | 等 `document.fonts.ready`，导出后抽查字体 |

**6.3 离线可用。** 交付物断网也要一模一样：

- 不引用任何 CDN：字体、脚本、图片全部本地相对路径。
- 字体优先用系统字体栈（见 `craft-typography-cjk.md` §1）。要用 webfont 就随包分发并子集化，只带用到的字重，子集化时保留 `halt`、`kern` 特性。
- 控制台不能有 404 和报错。`snippets/_render.cjs` 会把请求失败和脚本错误打印出来。

**6.4 性能。** 单张图片不超过 1MB，长边不超过 2880px；整个 deck 不超过 20MB。SVG 图解直接内联。大图用 `loading="eager"`（翻页式 deck 不要懒加载，截图时会漏图）。一页的 DOM 节点超过 600 个通常说明结构有问题。

**6.5 就绪信号。** 页面里有脚本排版（修孤字、量连接线、自适应字号）时，全部完成后设 `document.documentElement.dataset.ready='1'`。截图和导出等这个信号，不靠固定延时。

## 7. 验收流程

每页都走一遍，顺序固定。

1. **渲染**：按画布原生尺寸逐页截图（`_render.cjs`），不看缩小的总览图下结论。
2. **机检**：对每页跑 `deckLint(slide)`。P1 必须清零；P2 逐条处理或写明保留理由；P3 是提醒人工看。先用 `24-deck-lint.html` 这张故意做坏的页面确认检查器本身在工作。
3. **眯眼看**：把截图缩到 25%，还能认出主角、标题和分组，就过。认不出就是层级不够。
4. **逐项看**：字（孤字、断词、标点）、齐（版心线、基线、列对齐）、色（强调色几处、是否同一件事）、图（主体是否在、是否糊）、空（底部留白）。
5. **文字核对**：把页面 `innerText` 去掉空白后和源文案逐页比对，防止文字被裁掉或漏掉。
6. **每轮只修最严重的三个问题**，修完重新渲染再看。连续两轮找不出三个问题就停。改到第五轮还在大动，说明原型选错了，回到 §0。
7. **导出核对**：PDF 页数等于 slide 数，页面尺寸正确，抽查三页放大到 400% 看文字是否仍是矢量。

`deck-lint.js` 当前的规则：`out-of-canvas`、`clipped`、`tiny-text`、`low-contrast`、`text-on-image`、`orphan`、`gradient-text`、`tight-tracking`、`cjk-italic`、`side-stripe`、`nested-shadow`、`glow`、`card-soup`、`empty-bottom`、`too-many-sizes`。用 `data-lint-skip="规则名"` 可以对某个节点豁免，豁免要能说出理由。
