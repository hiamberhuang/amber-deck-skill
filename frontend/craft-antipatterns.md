# 反模式：哪些东西让一页看起来是 AI 做的

三类问题分开说：**AI 味**（模型的默认选择，谁做都长一样）、**代码味**（看得出是网页组件拼的）、**线框感**（结构对了但没有完成度）。每条给出可检测的特征和替换做法。方括号里是 `snippets/deck-lint.js` 的规则名，没有规则名的靠人看。

一个前提：下面每一条在某些场合都可以是正确选择。它们成为问题，是因为不看内容就默认出现。用户的要求或品牌规范明确指定了其中某一条时，照用户的来。

## 1. AI 味

### 1.1 版式

| 特征 | 怎么认出来 | 换成 |
|---|---|---|
| 三张等大卡片并排，每张“图标 + 小标题 + 两行字” | 3 个以上兄弟节点同尺寸、同结构、同底色 `[card-soup]` | 按内容性质选结构，见 `frontend-craft.md` §2.5 |
| 圆角方块里放一个图标，叠在标题上面 | 每张卡片第一个子元素是 40–56px 的圆角色块 | 去掉；真需要图标就放在标题左侧同一行 |
| 三个大数字排成一行，下面各一行小字 | 3–4 个等大数字块，没有参照物 | 一页一个主数字加参照条（`11-big-number`），其余进表格 |
| 所有内容居中 | 标题、正文、卡片全部 `text-align:center` | 默认左对齐；居中只给封面和引言 |
| 每个标题上面都有一行小号大写字母标签 | 标题前紧挨一个 11–13px、字距加宽的元素 | 删掉。只有它提供了标题里没有的信息（章节名、日期）才留 |
| 给不是步骤的东西编号 01 / 02 / 03 | 并列的要点前有装饰性大号数字 | 只有真正有先后的内容才编号 |
| 标题里只有一个词换了颜色或加了斜体 | `h1` 里有一个带颜色的 `span` | 整句一个颜色。要强调就把那个词写进结论 |
| 用“·”连接的元信息串：A · B · C | 一行里两个以上间隔号 | 拆成各自的位置，或只留最重要的一项 |
| 链接和按钮后面都带一个“→” | 文字结尾是箭头字符 | 幻灯片上没有可点的东西，删掉 |
| 每页结构都一样 | 连续三页同一个原型 | 相邻页换原型，疏密交替 |

### 1.2 颜色和表面

| 特征 | 怎么认出来 | 换成 |
|---|---|---|
| 紫色到蓝色的渐变、深底配青色或荧光绿 | 色相 250–330 的渐变；`#6366f1` 一类 | 用品牌令牌，一个强调色 |
| 渐变文字 | `background-clip:text` 加渐变 `[gradient-text]` | 实色，靠字号和字重 |
| 发光 | 零偏移的彩色 `box-shadow` 或 `text-shadow` `[glow]` | 中性色、向下偏移的两段阴影 |
| 圆角卡片左边一条粗色条 | `border-left` ≥ 3px 加圆角 `[side-stripe]` | 去掉色条；要强调就整块换底色 |
| 每张卡片都是细边框加大范围柔和阴影 | 所有卡片同一个 `rgba(0,0,0,.1)` 阴影 | 三层深度语言，见 `frontend-craft.md` §4 |
| 所有东西同一个圆角 | 父子元素圆角值相同 | 圆角同心：内 = 外 − 内边距 |
| 毛玻璃 | `backdrop-filter` | 不用（PDF 里也会丢） |
| 背景上的装饰：光斑、网格纸、噪点、斜条纹 | `radial-gradient` 渐隐到透明；`repeating-linear-gradient`；`feTurbulence` | 干净的底色。需要氛围就用真实照片 |
| 米色底 + 高对比衬线大标题 + 陶土橙 | 约 `#F4F1EA` 加约 `#D97757` | 这是当前最集中的一种默认风格。品牌本来如此可以用，否则换 |
| 近黑底 + 一个荧光色 | `#0B0B0B`、`#111` 加高饱和单色 | 同上 |

注意最后两条和本项目的关系：`tokens.css` 的暖白底配玫红，在色相上不属于“米色加陶土橙”，但结构相近（暖白底、单一强调色）。它是从真实交付稿里实测出来的品牌选择，照用。要避免的是在它上面再叠加其他默认特征，比如衬线大标题、每页的大写小标签。

### 1.3 字体和文案

| 特征 | 怎么认出来 | 换成 |
|---|---|---|
| 英文字体用 Inter、Roboto、Poppins、Space Grotesk、Playfair Display | 字体栈里出现这些名字 | 本项目用系统中文字体栈，不单独挑西文字体 |
| 用等宽字体写小标签，显得“技术” | 非代码内容用了 monospace | 正文字体 |
| 中文用斜体 | `font-style:italic` `[cjk-italic]` | 字重或强调色 |
| 全部是名词短语的标题 | 标题没有动词，是栏目名 | 标题写结论，是一个完整的判断 |
| 空话 | 赋能、打造、助力、全面、一站式、闭环（当形容词用）、新范式 | 写具体发生了什么，带数字 |
| 三段式排比和对仗 | 连续三个结构相同的短语；“不是 X，而是 Y” | 说一件事，说清楚 |
| 破折号过多 | 一页两个以上“——” | 逗号、冒号，或拆成两句 |
| 整齐得可疑的数字 | 3 倍、10,000+、99% | 真实数字加口径；没有就不写 |
| 捏造的引言、客户 logo、数据 | 文案里没有给出的内容 | 不编。留占位并在交付说明里列出 |
| 把过程写进页面 | “方案 A”“模板名”“（示例）”出现在成品里 | 删掉 |

### 1.4 动效

每个区块都淡入上移、每张卡片都有悬停效果、弹跳缓动、一直闪的小圆点、假的打字光标：这些是默认动效。一页最多一个有意义的编排。具体做法见 `../motion/`。

## 2. 代码味

看得出是前端组件库拼出来的页面，问题在于它按网页的习惯做了幻灯片。

| 特征 | 为什么不对 | 换成 |
|---|---|---|
| 网页的字号（14px 正文、12px 说明） | 幻灯片是隔着距离看的 | 正文 ≥ 16px，标题 ≥ 40px（1440 画布） `[tiny-text]` |
| 按钮、输入框、标签页、导航栏样式的元素 | 幻灯片上没有可操作的东西，这些只是在模仿界面 | 去掉。产品界面用真实截图装框展示 |
| 徽章和小药丸标签到处都是 | 把正文拆成了一堆小零件 | 一页最多一两个，用来标状态 |
| 组件库的默认样子（灰边框卡片、默认表格、默认图表配色） | 一眼认得出是哪个库 | 全部走令牌；图表手写 |
| 用 emoji 当图标 | 各平台渲染不一致，无头 Chrome 里可能是方框 | 一套线性图标，或不用图标 |
| 响应式布局残留 | 百分比宽度、`vw` 字号、媒体查询 | 固定画布，px |
| 仪表盘式的页面 | 六个以上小图表挤在一页 | 一页一个图，说一个结论 |
| 图表带图例、网格、坐标轴标题、工具提示 | 这是交互式图表的配置 | 直接标注，见 `craft-diagrams-dataviz.md` §8 |
| 代码块、终端窗口、JSON | 除非听众是工程师并且代码就是内容 | 用图解说明机制 |
| 留着滚动条或内容被裁掉 | 内容超出了盒子 `[clipped]` `[out-of-canvas]` | 拆页 |
| 字号种类很多、间距不成体系 | 15.5px、17px、间距 13px、22px | 字号和间距都取自台阶 `[too-many-sizes]` |

## 3. 线框感

结构是对的，但像没做完。

| 特征 | 怎么认出来 | 换成 |
|---|---|---|
| 全是灰色方框和 1px 边框 | 每块内容都有边框，没有任何实底 | 去掉大部分边框，用留白分组；主角给实底或白卡 |
| 没有主角 | 眯眼看，所有元素一样重 | 定一个主角，放大到占画面三分之一以上 |
| 层级只有两档 | 只有“标题”和“正文”两种字号 | 至少四档：标题、小标题、正文、说明，各差 1.25 倍以上 |
| 下半页是空的 | 内容挤在上面 `[empty-bottom]` | 见 `frontend-craft.md` §2.8 |
| 图片位是灰色占位块或渐变块 | `background:#eee` 的大方块 | 真实图片；没有就写明需要什么图 |
| 用基本形状拼的示意图 | 几个圆和方块代表“用户”“系统” | 真实截图，或按几何规则画的图解 |
| 线没接上、箭头歪、间隔不匀 | 连接线端点离节点 2–3px；节点间距不等 | 端点量出来，见 `craft-diagrams-dataviz.md` §1 |
| 孤字、断词、标点在行首 | 末行一两个字 `[orphan]` | `craft-typography-cjk.md` §4、§5 |
| 文字贴着容器边 | 内边距小于 16px | 卡片内边距 ≥ 22px，且不小于正文字号的 1.3 倍 |
| 对比度不够 | 浅灰小字 `[low-contrast]` | 可读文字最浅用 `--muted` |
| 截图直接贴在页面上 | 没有框、没有阴影，边缘和底色糊在一起 | 装框（`05`、`06`） |
| 图片被拉伸或主体被裁掉 | 没有 `object-fit` 或没指定焦点 | `.frame` 容器加 `--pos`（`21`） |

## 4. 纠偏过头

禁掉一个特征，模型会自动换一个相邻的替代品。比如：

- 禁了紫色渐变，换成青色渐变。
- 禁了三张卡片，换成四张卡片，或者三个带分隔线的等宽栏。
- 禁了大写小标签，换成带圆点的小标签。
- 禁了 Inter，换成 Space Grotesk。
- 禁了居中，所有页都变成一模一样的左文右图。

所以检查的对象是“有没有不看内容就做的选择”。验收时对每个显眼的设计决定问一句：这页的内容换成别的，这个决定还会一样吗？如果会，它就是默认值，需要重新想。

反过来，有明确理由的大胆选择不算问题：封面整页一个词、某一页全强调色底、一张图占满画布。一套 deck 里应该有一两页这样的页面。

## 5. 机检与人检的分工

机器能查的（`deck-lint.js`）：出画、被裁、字号下限、对比度、孤字、渐变字、中文字距过紧、中文斜体、左侧色条、卡中卡、发光、卡片汤、底部留白、字号种类。

必须人看的：主角是否成立、标题是不是结论、强调色是否指向同一件事、图片主体和质量、图解的线是否接上、文案里的空话和编造、相邻页是否雷同。

机检全过不等于这页好。它只保证这页没有硬伤。
