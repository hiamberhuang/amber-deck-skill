# Amber deck 页型目录（archetypes）

39 个页型，从 10 份真实 HTML deck（共 166 页）渲染实测得出。原稿缩略图和出处在团队私有包里；公开版给几何、密度和对应的可编辑原型（`kit-public/`，渲染图在 `kit-public/preview/`）。

**怎么读几何数据**：`原生` 是原稿画布上的 px（1280×720 或 1600×900），`@1440` 是换算到 1440×810 的值。`标题` 是 H1/H2 的位置与字号；`内容区` 是标题和副标题之下所有可见内容的外接框；`底部余量` 是内容下沿到页脚线（画布 92% 高度处）的距离，负数表示内容压到了页脚区。密度里的「网格覆盖」按 40×24 网格统计有文字、图片或色块的格子比例，「下三分之一填充」只统计画布下 1/3。数据由浏览器 `getBoundingClientRect` 实测。

**通用规则（实测得出）**

- 标题在 x=68、y≈94（@1440），45px/900，红色强调词用 `<em>`；副标题 19px 灰色，距标题 11px。94 页暖白页里标题字号中位数就是 40px（原生），不要每页改大小。
- 内容区从 y≈216 开始，一直填到 y≈752（页脚线上方）。原稿正文页下三分之一填充中位数是 80%（暖白）、90%（政府、案例证据）。**下三分之一留白超过一半，就是没做完。**
- 每页正文字数中位数：暖白 369 字，红黑 394 字，暗场 132 字，案例证据 150 字。文字少的页要用大图、大数字或机制图撑满，不要把三栏文字放大。
- 机制页一定要画出机制：节点、方向、回流、谁拍板。三栏文字加一条黑色结论条不是机制图（v2 试跑第 5、8 页的问题），请改用 A12、A15、A16、A22、A33、A34。
