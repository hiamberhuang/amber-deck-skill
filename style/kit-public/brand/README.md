# brand/ · Noumena 品牌层

只放 Noumena 自己的字标和公开品牌色。删掉整个文件夹、再删掉 index.html 里那行 `brand/brand.css`，kit 就回到中性占位色和 LOGO 虚线框。

- `wordmark.png` / `wordmark-white.png`：由快消通案试跑包里的 noumena-logo.png 裁切缩放，白色版只把黑色笔画换成白色，红色笔画保留。
- `brand.css`：`--accent #E4003A`、`--eyebrow #E9718E`、`--accent-soft #FDF1F4` 等，与 tokens.json 中的实测值一致。暗场强调色 `#DC0344` 取自反向黑客松。
