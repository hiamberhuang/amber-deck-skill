# Deck Starter Kit · 公开版

一份可以直接打开的 HTML deck，28 页，每页是一个页型原型，文字全是占位。没有客户名、logo、真实数字、人员、融资信息或内部产品名。品牌字标和品牌色只在 `brand/` 里，删掉这个文件夹就是中性版本。

## 打开

浏览器直接打开 `index.html`，不需要网络或构建。`preview/` 里是每页 1440×810 的渲染图，给不能运行浏览器的 AI 看。

| 操作 | 按键 |
|---|---|
| 下一步 / 上一步 | → 空格 PageDown / ← PageUp |
| 首页 / 末页 | Home / End |
| 概览（点缩略图跳页） | O 或 Esc |
| 全屏 | F |
| 动效开关 | M（系统设置为减少动态效果时自动关闭） |
| 打印 / 导出 PDF | P，每页一张 1440×810 |
| 深链 | `index.html#/9` 打开第 9 页，`index.html#loop-rings` 按 id 打开 |
| 截图模式 | `index.html?static` 关闭所有动效 |
| 分步揭示 | 给元素加 `data-step="1"`、`"2"`…，→ 逐个出现（示例见第 27 页） |

## 文件

```
index.html            所有页面；每页以 <!-- ═══ Kxx · Ayy 页型名 ═══ --> 开头
css/tokens.css        实测设计变量（字号、边距、色板、阴影），按 data-family 切换五个家族
css/runtime.css       舞台缩放、翻页、概览、打印、动效
css/archetypes.css    每个页型一段，以 /* ===== NN 名称 ===== */ 分隔
js/deck.js            无依赖运行时
brand/                Noumena 字标与品牌色（可删）
preview/              28 张渲染图
```

## 做一页新的

1. 在 `index.html` 里复制最接近的 `<section class="slide">…</section>`，改 `id` 和 `data-name`。
2. 页头只改三行：`.eyebrow`（4–8 字栏目名）、`.title`（一句判断，关键词放 `<em>`）、`.sub`（一句补充，不超过一行半）。没有副标题时给 section 加 `no-sub`。
3. 正文全部放进 `.body`。`.body` 固定在 y 216–752，原型的网格都按这个高度填满，**不要在 .body 里自己设高度**。
4. 家族：在 section 上写 `data-family="redblack | dark | gov | case"`，不写就是暖白。商务通案不要整套用 dark。
5. 改完用 `?static` 打开，逐页截图看：标题位置和字号是否与其他页一致、有没有文字溢出、下三分之一是否填满。

## 密度底线（实测）

- 暖白正文页：每页约 370 字，下三分之一填充 ≥ 70%。
- 暗场页：每页约 130 字，靠大字、实景撑满。
- 机制页至少要有：节点、方向箭头、回流线、人工拍板点。只有文字栏的页不算机制页。
- 截图占画布宽度 60% 以上；数字页的大数字 ≥ 48px（@1440）。
