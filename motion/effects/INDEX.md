# 动效库索引（effects/）

共 39 个单文件效果，其中 Amber 签名效果 11 个，其余为原创实现。无头浏览器验收通过 39 / 39。

## 怎么用

- 每个文件都是 1440×810 的独立页面，双击即可在浏览器打开；GSAP 3.13.0 由固定版本 CDN 引入。离线或 CDN 加载失败时，页面直接显示静态终态，不报错。
- 通用按键：→ / 空格 / PageDown / 滚轮 前进一步，← 回退，E 跳到终态，R 重播，H 隐藏底部提示条。单击画面也是前进。
- 网址参数：`?end` 直接显示静态终态（打印、导出 PDF、截图用）；`?rm` 模拟系统“减少动效”；`?clean` 隐藏提示条。
- 减少动效：系统开启“减少动效”时不播放任何补间和循环。无步骤的效果直接显示终态；有步骤的效果按键时瞬间切到下一停点。
- 搬进自己的 deck：复制该文件 `/* ---- effect ---- */` 之后的 CSS、`#stage` 内的 HTML 和最后一段脚本；共享运行时（`window.FX`）放一次即可。停点用时间轴标签 `s1`、`s2`… 标记。

表中“讲者按键”指在该页内部的步进，不含翻页。
